# BookNook

A modern digital library platform for discovering, borrowing, and managing books online.

**Live Site:** https://booknob-client.vercel.app

## Features

- Browse and search a growing collection of books across multiple categories.
- Create an account and manage your personal library with ease.
- Borrow and return books with automatic due-date tracking.
- Add, edit, and delete your own books to share with the community.
- Beautiful, responsive UI with dark and light mode support.

## Technologies Used

- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS v4
- shadcn/ui (Base UI)
- Better Auth
- MongoDB
- React Hot Toast
